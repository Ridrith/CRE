# Conflict Resolution Engine (CRE) v2.0

Full RPG rules addon for the **Iron Circle** WoW RP guild.

See the root [README.md](../README.md) for complete documentation, rules reference, and installation instructions.

## Quick Start

1. Type `/cre` to open the main window.
2. Go to the **Profile** tab to create your character.
3. Distribute your 10 attribute points and select your class.
4. Use the **Dice**, **Combat**, **Traits**, and **Reference** tabs for in-game play.
